# Archived experiments

This folder preserves early, duplicate, or one-off experiments that are not part of the supported project workflow.

- `legacy_experiments/gol_pixel_sayici_legacy.py`: older duplicate inference implementation.
- `legacy_experiments/a.py`: incomplete GPU inspection experiment.
- `legacy_experiments/pikseltest.py`: one-off pixel-count check with a hard-coded sample path.

They are retained for project history but should not be used as the primary entry points. Use the scripts documented in the root `README.md` instead.
